# R8 1.0：视觉符号与约束求解

本文命令在仓库的 `pipelines/` 目录执行。

当前协议：`r8-symbolic-execution/1.0`。读取变量、单位和约束，通过可复算的算术、几何或 Z3 求解并回代。固定 z3-solver==5.1.0.0；视觉输入、约束可解和答案正确属于不同验证层级。

## 对应题型

Video-MME-v2 / Numerical Calculation；EgoLifeQA / EntityLog（由总价和数量求单价）。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r8_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r8 --config configs/r8_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r8/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

`--r8-protocol` 指定公开观察权限，`--r8-mode` 选择 A–G（默认 G）。`--variables-input` 为变量回放；oracle 输入必须配合 `--diagnostic`，不能计作正式证据。`--require-choice` 显式保留未解决题的强制输出回退，不能把它当作证据充分。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r8.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R8Config, R8Request, R8VideoAgent
```

请求字段见 [`r8` 源码](../../qwen3vl_agent/r8/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
