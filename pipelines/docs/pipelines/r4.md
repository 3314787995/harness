# R4 5.7：清单构建与集合归约

本文命令在仓库的 `pipelines/` 目录执行。

当前协议：`r4-inventory-v5.7`。建立有来源的实例、类别或文字清单，完成去重、集合归约和负证据核验。当前 5.7 使用语义观察、定向纠错及独立最佳作答；最佳答案不会覆盖集合归约与证据状态。

## 对应题型

Video-MME / Counting Problem（实例数）、Object Recognition（未讨论项）；VSI-Bench / Object Count。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r4_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r4 --config configs/r4_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r4/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

支持 `--r4-policy` 读取公共集合约定 JSON、`--subtitle`、范围、checkpoint 和 resume。可输出 list；不支持 interval 输出。5.7 的最佳作答与 `evidence_status`、集合归约分别保留，准备动作、模糊类别及负证据必须按现有规则处理。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r4.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R4Config, R4Request, R4VideoAgent
```

请求字段见 [`r4` 源码](../../qwen3vl_agent/r4/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
