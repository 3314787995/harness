# R3 5.4：查询驱动时间证据

本文命令在仓库的 `pipelines/` 目录执行。

当前协议：`r3-5.4`。按事件单位、范围和运算生成必要观察，维护轻量候选并作时间归约。当前 5.4 处理长活动实例与局部核验范围，将已取得的事实带入终局；不要求每题先构建完整全片账本。

## 对应题型

MVBench / Action Count、Character Order；Video-MME / Temporal Perception（事件顺序、时长）；Video-MME-v2 / Repetitive Action Counting。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r3_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r3 --config configs/r3_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r3/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

支持 `--r3-policy` 读取公共任务约定 JSON，以及 `--given-interval`、`--allowed-scope`、`--query-scope`、`--execution-subtype`、`--checkpoint`、`--resume`。先固定事件单位及 onset／offset 等时间口径。统一入口的当前路径不接收字幕；不能据机制映射宣称所有音频／文本条件已适配。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r3.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R3Config, R3Request, R3VideoAgent
```

请求字段见 [`r3` 源码](../../qwen3vl_agent/r3/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
