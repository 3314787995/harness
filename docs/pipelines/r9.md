# R9 1.0：空间场景建模与查询

当前协议：`r9-spatial-query/1.0`。绑定对象、视角与查询参考系，建立足够解题的空间关系，处理方向、距离、尺度和路线。绝对尺度不足时保留不确定性，不把单目估计表述为精确重建。

## 对应题型

VSI-Bench / Relative Direction、Relative Distance、Route Plan；Video-MME-v2 / Spatial Understanding（参考系、跨视角子型）。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r9_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r9 --config configs/r9_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r9/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

使用 `--r9-mode` 选择 B0–B4（默认 B4）、`--r9-unit` 指定公共数值单位；`--r9-allow-unresolved` 显式允许未解决时为空。对象身份、查询参考系、方向定义和尺度来源必须完整保留。给定路线补转向不自动等于全局最短路径规划。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r9.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R9Config, R9Request, R9VideoAgent
```

请求字段见 [`r9` 源码](../../qwen3vl_agent/r9/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
