# R1 3.1：定向定位与局部取证

当前协议：`r1-local-evidence/3.1`。定位问题所指的片段，保留带来源的局部观察和反证，再核验答案。当前 3.1 增加字段绑定复核、可回答来源筛选及有界补看；结果命名空间继续为 `r1_v3`。

## 对应题型

Video-MME / OCR Problems（局部文字）、Object Recognition（普通目标）、Attribute Perception（直接属性）。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r1_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r1 --config configs/r1_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r1/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

`--given-interval START END` 提供已知片段；`--allowed-scope` 限制可读取范围，`--query-scope` 指定问题范围。支持原生选择题及已有结果协议；保持 3.1 的有界补看预算。`--config configs/r1_8b.yaml` 内仍使用 `r1_v3:` 键。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r1_v3 --help
```

Python 类型入口：

```python
from qwen3vl_agent import R1Config, R1Request, R1VideoAgent
```

请求字段见 [`r1_v3` 源码](../../qwen3vl_agent/r1_v3/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
