# R5 3.1：分段全局综合

当前协议：`r5-direct-v3.1`。任务解析后分段观察、合并并综合事实。当前 3.1 将 Merge 中未登记但真实存在的输入以 passthrough_refs 原样携带，保留来源链；合法引用不等于独立语义验证。

## 对应题型

Video-MME / Information Synopsis（事实综合）；MLVU / Video Summarization；EgoSchema / Long-form Video QA（整体行为）。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r5_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r5 --config configs/r5_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r5/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

支持 `--subtitle`、`--asr`、范围、checkpoint 和 resume；多选或自由文本输出。3.1 的 `passthrough_refs` 保留真实输入，但仍占用后续上下文；`verification_status=not_performed` 不应解读为已核验。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r5.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R5Config, R5Request, R5VideoAgent
```

请求字段见 [`r5` 源码](../../qwen3vl_agent/r5/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
