# R7 1.0：假设与未来推演

当前协议：`r7-world-execution/1.0`。固定当前事实、可观察范围和假设条件，推演候选未来或替代状态；事实与反事实状态分开维护，不读取预测目标之后的真值片段。

## 对应题型

MVBench / Action Prediction、Counterfactual Inference；Video-MME-v2 / Future Event Prediction、Counterfactual Reasoning。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r7_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r7 --config configs/r7_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r7/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

必须提供原始 choices，支持 `--r7-protocol` 公共观察权限、`--facts-input` 合法事实回放、`--allowed-interval`、`--query-time`、`--observation-cutoff`、checkpoint／resume。模式 B0–B4 及 B4-uniform 通过 `--r7-mode` 选择；指定协议与 CLI 范围冲突时拒绝。不要把 query_time 与允许观察范围混同。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r7.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R7Config, R7Request, R7VideoAgent
```

请求字段见 [`r7` 源码](../../qwen3vl_agent/r7/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
