# R2 1.5：连续动态与实体状态追踪

当前协议：`r2-entity-time/1.5`。维护实体—时间状态，处理属性变化、动作正反、轨迹、遮挡和周期。当前 1.5 保留证据质量诊断，正常终局输出合法选项；有答案不等于证据充分。

## 对应题型

MVBench / Action Antonym、Object Shuffle；TOMATO / Rotation、Direction。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r2_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r2 --config configs/r2_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r2/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

支持 `--allowed-interval START END` 多次传入、`--query-time`、`--observation-cutoff`、`--subtitle`、`--asr`、`--checkpoint`、`--resume`。原选项与终局证据状态分开保存；缺失运动证据不应被当作静态已确认事实。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r2.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R2Config, R2Request, R2VideoAgent
```

请求字段见 [`r2` 源码](../../qwen3vl_agent/r2/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。
