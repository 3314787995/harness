# R6 1.0：证据约束关系推理

当前协议：`r6-evidence-relations/1.0`。Compiler、Observer、Relation Checker、Verifier 共享冻结模型，维护带来源事实与关系，针对证据缺口补看并隔离核验。已有 1.0 实现与 CPU 验证记录，真实 GPU smoke 尚未执行；真实音频 Provider 尚未启用。

## 对应题型

Video-MME / Action Reasoning（非明示原因）；Video-MME-v2 / Causal Reasoning、Symbolic/Metaphorical Interpretation。这些是有条件的机制对应，完整分流及待确认项见 [benchmark 对照](../benchmark_mapping.md)。

## 安装与单题运行

使用 Python 3.11，按 [README](../../README.md) 安装模型依赖；R8 还需 r8 extra。设置 `QWEN3VL_MODEL_PATH` 指向所需权重快照，读取 `configs/r6_8b.yaml` 中的预算、attention 和设备配置。

```bash
python -m qwen3vl_agent.cli --strategy r6 --config configs/r6_8b.yaml --video path/to/video.mp4 --query "REPLACE_WITH_ORIGINAL_QUESTION" --choice "REPLACE_WITH_ORIGINAL_OPTION_A" --choice "REPLACE_WITH_ORIGINAL_OPTION_B" --trace-output runs/r6/trace.json
```

示例参数是占位符，必须替换成真实题目与原始选项；不把参考答案放入问题或协议文件。

## 输入协议与可选参数

支持 `--allowed-interval`、`--query-scope`、`--observation-cutoff`、`--subtitle`、`--asr`、`--checkpoint`、`--resume`。`--r6-protocol` 提供公共权限 JSON；与 CLI 同名字段同时存在时协议文件生效，建议只采用一种方式。`--r6-mode` 可选 pipeline／direct／captions／question_only。文本需满足 allowed_modalities、文件路径和 aligned_only 策略；真实音频尚未启用。

单题统一 CLI 与批量 evaluator 的参数名可能不同，完整接口以各入口帮助为准：

```bash
python -m qwen3vl_agent.cli --help
python -m qwen3vl_agent.r6.evaluate --help
```

Python 类型入口：

```python
from qwen3vl_agent import R6Config, R6Request, R6VideoAgent
```

请求字段见 [`r6` 源码](../../qwen3vl_agent/r6/)。所有模型加载均需显式调用 `agent.load()`，用完在 `finally` 中执行 `agent.unload()`。统一 CLI 已处理该生命周期。

## 输出与验证

答案打印到标准输出，`--trace-output` 保存 metadata；`--show-metadata` 显示完整记录。保留原结果结构，答案、证据质量与停止原因不能互相代替。控制逻辑测试使用 FakeModel／合成媒体，不证明真实视频语义正确率。

本发布快照的 CPU 检查、已有失败与整理前后对照见 [验证记录](../validation.md)。本次没有运行 GPU 或完整 benchmark 测评。

## 开发清单预检

```bash
python -m qwen3vl_agent.r6.evaluate preflight --manifest examples/r6/requests.jsonl --config configs/r6_8b.yaml --output runs/r6/preflight.json
```

清单内媒体相对 `examples/r6/` 定位；原视频不随代码分发，缺媒体时应明确报告 media_unavailable。开发题不能作为独立泛化评测。
